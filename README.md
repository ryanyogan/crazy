# Crazy

One place that reads a person's work and personal tools and tells them what to do with today.

```sh
pnpm install
pnpm dev          # http://localhost:3000
```

No keys are needed: without Clerk configured you arrive as the demo user. Start with
[`AGENTS.md`](AGENTS.md) for the layout, rules and commands, [`CONTEXT.md`](CONTEXT.md) for the
vocabulary, and [`docs/BRIEF.md`](docs/BRIEF.md) for where the project stands.
